# NewTab

Личная стартовая страница браузера. Это статическая HTML/JS-страница без сборки:
`index.htm` подключает локальные библиотеки и почти весь интерфейс создаётся в
`base.js` после загрузки пустого `body`.

## Как открыть

Через GitHub Pages:

```text
https://dygdyg.github.io/DygDygWEB/NewTab/
```

Локально можно открыть `index.htm` напрямую. Если браузер режет часть внешних
запросов, проверь поведение через обычный локальный static server.

## Основные файлы

- `index.htm` - точка входа, подключает jQuery, moment, Google Identity Services,
  `key_fav.js`, стили, `start.js` и `base.js`.
- `start.js` - инициализация, миграция и совместимость настроек в `localStorage`.
- `base.js` - основная логика: поиск, карточки, настройки, фон, часы, импорт/экспорт,
  Google Drive sync.
- `key_fav.js` - меняет favicon при нажатиях клавиш.
- `style.css` - весь основной layout и визуальный стиль.
- `BebasBold.css`, `anistar.*` - локальный шрифт для карточек и часов.
- `favicon/` - SVG-фавиконки.
- `logos/` - готовые картинки для превью карточек; могут использоваться вручную
  как URL миниатюр.
- `snow/`, `snow.js`, `yandex_motnya/` - отключённые/сезонные новогодние эффекты.
- `click_key.ogg`, `copy.mp3` - звуки ввода и копирования.

## Данные и настройки

Основной формат настроек живёт в `localStorage` текущего origin под ключом
`newtab.settings.v2`:

```json
{
  "version": 2,
  "updatedAt": "2026-07-18T03:00:00.000Z",
  "background": "https://example.com/bg.jpg",
  "showCards": true,
  "clockBehavior": "hover",
  "volume": 100,
  "cards": [
    { "name": "YouTube", "url": "https://youtube.com/feed/subscriptions", "image": "" }
  ]
}
```

Для совместимости `start.js` продолжает читать и записывать старые ключи:

| Ключ | Назначение |
| --- | --- |
| `newtab.settings.v2` | Новый JSON-формат настроек. |
| `newtab.googleDriveClientId` | Пользовательский override Google OAuth Client ID для синхронизации с Drive. |
| `newtab.googleDriveConsentGranted` | Флаг, что пользователь уже дал Google Drive consent. |
| `newtab.googleDriveAccessToken` | Короткоживущий Drive access token с expiry для auto-sync без popup на каждую вкладку. |
| `newtab.googleDriveAutoSync` | `true`/`false`, включает сверку локальных настроек с Google Drive при открытии вкладки. |
| `newtab.serverAuthToken` | Токен сессии PHP-сервера для получения свежего Google Drive access token без повторного Google popup. |
| `newtab.serverTokenBaseUrl` | Необязательный override адреса PHP token server. По умолчанию `https://server.dygdyg.ru/newtab`. |
| `timezones` | Два IANA timezone id для часов, например `Europe/Moscow` и `Asia/Vladivostok`. |
| `clockBehavior` | `fixed` показывает выбранный режим постоянно, `hover` показывает часы, когда мышь вне страницы. |
| `urls` | Список URL карточек через запятую. |
| `names` | Подписи карточек через запятую. Если имя пустое, берётся домен. `*` скрывает подпись. |
| `images` | URL миниатюр карточек через запятую. Индексация исторически сдвинута на `+1`. |
| `background` | URL фоновой картинки. |
| `ShowCard` | Показывать карточки или режим часов. |
| `volume` | Громкость клика, 0-100. |

Если `newtab.settings.v2` отсутствует, настройки автоматически мигрируют из старых
ключей. После сохранения новый формат также перезаписывает старые ключи, чтобы старый
код и существующие профили не ломались.

Верхняя панель настроек разделена на группы:

- Основные настройки: ползунок меняет громкость, `Фон` меняет фон.
- Последняя плитка `+ Карточка` появляется в режиме настроек и добавляет новую карточку без перезагрузки страницы.
- Часы: два поля часовых поясов с выпадающими вариантами и текущим UTC offset. Можно вводить полный IANA id (`Europe/Moscow`) или часть названия (`moscow`), оно будет нормализовано через `moment-timezone`.
- `По умолчанию` выбирает, что показывать при открытии: карточки или часы.
- `Появление часов` выбирает поведение: фиксированный выбранный режим или старое hover-поведение, где часы появляются при уходе мыши со страницы.
- При наведении, клике или фокусе на блок выбора часовых поясов карточки временно скрываются и принудительно показываются часы. После ухода мыши и фокуса возвращается прежний режим, без сохранения `showCards`.
- Google Drive: если access token не найден или истёк, показывается только `Войти в Google` и чекбокс `Авто`. После входа появляются ручные кнопки `Загрузить` и `Сохранить`.
- В списке загрузки Google Drive рядом с каждым бэкапом есть `Удалить`; удаление требует подтверждения.
- Локальный бэкап: `Импорт` загружает настройки из JSON-файла, `Экспорт` скачивает JSON-бэкап.
- Красная кнопка закрывает верхнюю панель настроек.

Настройки открываются как верхняя панель, а не отдельное модальное окно. В режиме
настроек:

- клик по карточке открывает popup с её `name`, `url` и `image`;
- правый клик по карточке также открывает popup и включает режим настроек;
- карточки можно перетаскивать мышью, новый порядок сохраняется сразу;
- добавление, удаление и изменение карточек перерисовывает список без reload страницы;
- обычное открытие ссылок отключено, пока включён режим настроек.

## Google Drive Sync

Синхронизация использует Google Drive API и скрытую папку `appDataFolder`.
Файл называется `newtab-settings.json`.

Основной способ авторизации для GitHub Pages - PHP token server:

```text
https://server.dygdyg.ru/newtab/
```

Страница хранит только `newtab.serverAuthToken`. Google `refresh_token` и
`client_secret` остаются на сервере, а сайт запрашивает у `/api/token.php` только
короткоживущий Drive `access_token`. Старый browser-only Google Identity Services
flow оставлен как fallback для локальных тестов или аварийного режима.

При каждом открытии вкладки NewTab делает тихий auto-sync, если включён чекбокс
`Авто` и есть серверная сессия или живой access token:

- если файла в Drive нет, текущие локальные настройки загружаются в Drive;
- если Drive свежее по `updatedAt`, настройки скачиваются и страница перезагружается;
- если локальная копия свежее, она загружается в Drive;
- если время совпадает с точностью примерно до секунды, ничего не происходит.

Загрузка страницы сама по себе не обновляет `updatedAt`. Его меняют только локальные
изменения настроек, импорт старого JSON или ручное сохранение.

Для browser-only fallback можно вшить один общий Client ID в `base.js`:

```js
const GOOGLE_DRIVE_DEFAULT_CLIENT_ID = '...apps.googleusercontent.com';
```

Client ID не является секретом. Client secret в браузерный код добавлять нельзя.
Для основной PHP-схемы Client ID и Client Secret лежат только в `config.local.php`
на сервере.

Чтобы получить Client ID:

1. Создать OAuth Client в Google Cloud Console с типом `Web application`.
2. В Authorized JavaScript origins добавить `https://dygdyg.github.io`.
3. Для локальной разработки добавить `http://127.0.0.1:5500`.
4. Включить Google Drive API.
5. Вставить Client ID в `GOOGLE_DRIVE_DEFAULT_CLIENT_ID`.

Если `GOOGLE_DRIVE_DEFAULT_CLIENT_ID` пустой, при первом нажатии Drive-кнопки появится
prompt. Значение из `newtab.googleDriveClientId` в `localStorage` имеет приоритет над
дефолтным ID и нужно только для ручного override.

Используемый scope:

```text
https://www.googleapis.com/auth/drive.appdata
```

Access token кэшируется в `localStorage` вместе со сроком действия. Если включён
PHP token server, после истечения access token страница тихо запросит свежий токен
у сервера. Без сервера это не refresh token: после истечения срока Google может
снова попросить выбрать аккаунт или подтвердить доступ.
Scope ограничен `drive.appdata`, то есть токен даёт доступ только к скрытым данным этого
приложения.

Если серверной сессии нет и токен истёк, auto-sync молча пропускается до явного
нажатия `Войти через сервер` / `Войти в Google`. Это сделано специально, чтобы
новая вкладка не открывала OAuth-окно сама по себе.

## Поиск и горячие клавиши

В поле поиска:

- `Enter` - открыть URL или выполнить поиск в Google.
- `Shift+Enter` - поиск через Yandex.
- `Ctrl+Enter` - поиск в YouTube.
- `Alt+Enter` - поиск в animego.org.
- Если введён прямой URL с `http://`, `https://`, `file://`, `ftp://`, `steam://`
  или `magnet:?`, он открывается напрямую.
- Простые математические выражения показывают результат; клик по результату копирует его.

Глобально:

- `Ctrl+B` / `Meta+B` - экспорт всех ключей `localStorage` в prompt и обратный импорт
  из отредактированного JSON.
- `F8` - переключает debug-режим `key_fav.js`, при котором canvas favicon добавляется
  в body.
- `Ctrl+F8` - запускает случайную смену favicon-символов.
- Любая клавиша меняет favicon на символ этой клавиши.

## URL-параметры

- `?options=true` - открыть настройки сразу.
- `?search=false` - скрыть поисковое поле.
- `?tz1=<text>` - подобрать первую таймзону по подстроке, например `moscow`.
- `?tz2=<text>` - подобрать вторую таймзону, например `Vladivostok`.
- `?ShowCardF=true` - временно принудительно показать карточки, игнорируя сохранённое `clockBehavior`.
- `?ShowCardF=false` - временно принудительно показать часы, игнорируя сохранённое `clockBehavior`.
- `?screenshotmachine=true` - использовать Screenshot Machine для превью карточек
  вместо `server.dygdyg.ru/shot.php`.

## Внешние сервисы

- `ipwho.is` - получает IP и флаг страны для нижнего индикатора.
- `server.dygdyg.ru/newtab/api/token.php` - основной способ получить свежий Drive
  access token через PHP token server.
- `accounts.google.com/gsi/client` - fallback Google Identity Services для Drive OAuth.
- `googleapis.com/drive/v3` - чтение/запись `newtab-settings.json` в `appDataFolder`.
- `server.dygdyg.ru/my_ip.htm` - открывается по клику на флаг.
- `server.dygdyg.ru/shot.php?url=...` - дефолтные screenshots для карточек без
  ручной миниатюры.
- `google.com/s2/favicons` - favicon для карточек.
- Google/Yandex/YouTube/animego.org - поисковые переходы.

Если блокировщик рекламы режет `ipwho.is`, нижний индикатор показывает предупреждение.

## Осторожно при правках

- Не менять формат `localStorage` без миграции: это личные настройки стартовой страницы.
- Сохранять совместимость со старыми ключами `urls`, `names`, `images`, `background`,
  `ShowCard`, `volume`.
- Не обновлять `updatedAt` при простом чтении настроек на старте страницы, иначе auto-sync
  будет считать локальную копию свежей при каждом открытии.
- Особенно аккуратно с массивом `images`: старые JSON-бэкапы хранят пустой `images[0]`,
  поэтому картинка для `urls[i]` лежит в `images[i + 1]`. Нельзя fallback-ом брать
  `images[i]` для пустых значений, иначе ручные обложки съедут на соседние карточки.
- Не удалять `logos/`, даже если прямых импортов нет: это удобный набор локальных
  thumbnail-ассетов.
- Не включать `snow.js` / `yandex_motnya` автоматически без проверки: это сезонные эффекты
  со звуками и большим количеством DOM.
- Не коммитить реальные экспортированные JSON-настройки, если там есть личные ссылки.
