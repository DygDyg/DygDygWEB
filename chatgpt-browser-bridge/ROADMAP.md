# Roadmap

Roadmap отражает направление разработки, но не является гарантированным графиком релизов.

## 0.18.0 — Developer Experience

Цель: сделать Bridge удобным для продолжительной разработки и подготовить репозиторий к GitHub.

### Documentation

- [x] создать базовые `README.md`, `PROJECT.md`, `ROADMAP.md`, `CHANGELOG.md`;
- [x] задокументировать архитектуру;
- [x] создать справочник реализованных инструментов;
- [x] задокументировать транзакции и историю;
- [ ] описать установку, обновление и диагностику;
- [ ] добавить `CONTRIBUTING.md`;
- [ ] выбрать и добавить лицензию;
- [ ] поддерживать документацию при каждом изменении протокола.

### Repository hygiene

- [x] добавить `.gitignore`;
- [x] исключить `.cbb-backup-*`, `.cbb-batch-*`, `.cbb-transaction-*` и временные файлы;
- [ ] перенести разовые миграционные сценарии в архив или удалить после проверки;
- [ ] добавить команду очистки старых backup-файлов;
- [ ] документировать политику хранения резервных копий.

### Batch read

- [x] реализовать `file.read.batch`;
- [x] ограничить число файлов и общий размер ответа;
- [x] возвращать SHA-256 и признак обрезки для каждого файла;
- [x] поддержать общий workspace и индивидуальные workspace;
- [x] добавить сводку результата в toolbar;
- [x] реализовать `file.read.batch.tree`;
- [x] добавить `recursive`, `pattern`, `extensions` и `exclude`;
- [x] пропускать build-каталоги и `.cbb-*`;
- [ ] протестировать `continue_on_error` и достижение общего лимита;
- [ ] добавить glob по полному относительному пути, а не только имени файла.

### Dashboard

- [x] создать отдельное приложение `BridgeDashboard.exe`;
- [x] запускать или активировать Dashboard через `dashboard.open`;
- [x] добавить `dashboard.status`;
- [x] режим Always on Top;
- [x] сохранять размещение и размер окна;
- [x] отображать состояние Native Host и список workspace;
- [x] отображать последнюю команду и результат;
- [x] отображать статистику команд, ошибок и длительности;
- [x] отображать список последних операций;
- [x] добавить кнопку запуска Dashboard в popup расширения;
- [x] безопасно обмениваться состоянием через атомарный JSON state-файл;
- [ ] индикатор генерации ответа ChatGPT на стороне расширения;
- [ ] кнопки History, Rollback, Undo, Build, Open Workspace;
- [ ] компактный режим виджета для второго монитора;
- [ ] передача состояния ожидания пользовательского подтверждения.

### Notifications

- [ ] звук окончания ответа;
- [ ] отдельные сигналы для успеха, ошибки и ожидания подтверждения;
- [ ] включение/отключение в настройках;
- [ ] регулировка громкости или использование системного звука;
- [ ] защита от повторного сигнала при DOM-перерисовке ChatGPT.

### TODO subsystem

- [ ] определить модель задачи и подзадачи;
- [ ] хранить задачи по workspace;
- [ ] статусы `todo`, `doing`, `blocked`, `review`, `done`;
- [ ] приоритет и зависимости;
- [ ] инструменты create/list/update/complete;
- [ ] отображение в Dashboard;
- [ ] связывать задачи с transaction ID и history;
- [ ] поддержать разбиение пользовательской задачи на подзадачи.

## 0.19.0 — Project Management

Цель: превратить Bridge в управляемое рабочее пространство для длительных AI-задач.

- [ ] Kanban-представление задач;
- [ ] milestones и версии;
- [ ] зависимости между задачами;
- [ ] журнал инженерных решений;
- [ ] project memory;
- [ ] привязка изменений и проверок к задачам;
- [ ] автоматическое обновление статуса TODO после commit;
- [ ] профили verify-команд для workspace;
- [ ] именованные snapshots проекта;
- [ ] восстановление snapshot;
- [ ] отчёт по завершённой задаче.

## 0.20.0 — AI Workspace

Цель: безопасные полуавтоматические инженерные циклы.

- [ ] автоматический план выполнения задачи;
- [ ] чтение только релевантных файлов;
- [ ] цикл build → diagnose → patch → verify;
- [ ] лимиты количества итераций;
- [ ] остановка и запрос решения пользователя;
- [ ] автоматическое обновление документации;
- [ ] генерация release notes;
- [ ] отчёт о рисках перед крупной транзакцией;
- [ ] восстановление контекста незавершённой сессии.

## Backlog

- пакетная запись файлов;
- создание и удаление файлов внутри транзакции;
- безопасные операции перемещения и переименования;
- полноценный граф истории;
- очистка истории и резервных копий;
- импорт/экспорт настроек;
- поддержка других Chromium-браузеров;
- подпись и автоматическая доставка сборок;
- интеграция с Git без замены встроенной системы rollback;
- тестовый проект и автоматические интеграционные тесты Native Messaging.
